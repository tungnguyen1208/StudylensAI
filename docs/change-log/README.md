# StudyLens AI change log

This directory records material, verified product and architecture decisions.
The newest record is listed first. It supports later SRS/SDS consolidation but
does not replace the source SRS/SDS documents.

Create a record when a change affects a business rule, public contract, data
model, integration architecture, core UX flow, or acceptance criterion. Do not
create a standalone record for formatting, typo-only, or behavior-preserving
refactoring work.

Use `template.md`, name records `YYYY-MM-DD-vX.Y-short-slug.md`, and set their
status to `proposed`, `accepted`, `implemented`, or `superseded`. A record may
be `implemented` only after the stated verification has passed. Before planning
related work, read the latest applicable record.

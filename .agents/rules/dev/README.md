# Developer Role Rules

These files are the detailed role rules and task backlogs for the three
StudyLens developers.

Use this mapping:

| Developer | Rule file | Custom agent |
|---|---|---|
| Dev 1 | `dev1-persistent-activation.md` | `.codex/agents/dev1-persistent-activation.toml` |
| Dev 2 | `dev2-session-quiz.md` | `.codex/agents/dev2-session-quiz.toml` |
| Dev 3 | `dev3-assessment-history.md` | `.codex/agents/dev3-assessment-history.toml` |

Each developer should keep personal machine settings minimal. Do not copy these
rules into a personal `AGENTS.md`; keep the shared source of truth in this
folder.
